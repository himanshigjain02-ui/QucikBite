# 🍔 QuickBite

A mobile-first food ordering app prototype — browse dishes, build a cart, place orders, and plan group lunches. Built as a single self-contained HTML file with vanilla HTML, CSS and JavaScript (no build step, no dependencies).

## 🔗 Live Demo

**[Try QuickBite here](https://YOUR-USERNAME.github.io/QuickBite/)**

> Replace `YOUR-USERNAME` with your GitHub username after enabling GitHub Pages (see below).

Best viewed on a phone, or on desktop where it appears in a phone-sized frame. Supports light and dark system themes.

## 🚀 Run Locally

Just open `index.html` in any modern browser. No install or server needed.

## 🌐 Deploy with GitHub Pages

1. Create a new repository named `QuickBite` on GitHub.
2. Upload `index.html`, `README.md` and `.nojekyll` (or push via git, below).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose **main** and **/ (root)**, then **Save**.
5. After a minute, your app is live at `https://YOUR-USERNAME.github.io/QuickBite/`.

### Using git

```bash
git init
git add .
git commit -m "Initial commit: QuickBite"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/QuickBite.git
git push -u origin main
```
